# v0.5 — Engineering Quality & Portfolio Release

v0.5 focuses on reproducibility, verification and presentation rather than adding another language feature.

## Added

- CI jobs for .NET build/test, TypeScript extension compilation and LLVM/WebAssembly execution.
- Docker toolchain containing .NET runtime, Clang/LLVM, LLD and Node.js.
- Docker Compose conveyor demonstration.
- PowerShell and Bash demo scripts.
- Additional semantic and PLC runtime tests.
- Architecture, demo and interview documentation.
- Changelog, contribution guidance, security/scope statement and editor configuration.

## Quality goal

A reviewer should be able to clone the repository, understand the architecture quickly, run tests, reproduce the compiler pipeline and execute the same conveyor program through both the managed PLC runtime and the WebAssembly backend.
