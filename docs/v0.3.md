# PLCFlow v0.3 — Language Server

PLCFlow v0.3 adds a standalone C# Language Server that reuses the compiler frontend and semantic analyzer.

## Implemented LSP features

- Live syntax and semantic diagnostics for `.st` files
- Hover information for declared variables, PLC I/O addresses, and TON members
- Completion for Structured Text keywords and declared symbols
- `TON` member completion (`Q`, `ET`)
- Go to definition for declared variables
- Full-document synchronization between VS Code and the server

## Architecture

```text
VS Code Extension (TypeScript)
        |
        | Language Server Protocol / stdio
        v
PLCFlow.LanguageServer (C#/.NET)
        |
        v
PLCFlow.Compiler
  Lexer -> Parser -> AST -> Semantic Analyzer
```

The language server is intentionally a separate process from the VS Code extension. This keeps compiler intelligence reusable by other editors or clients.
